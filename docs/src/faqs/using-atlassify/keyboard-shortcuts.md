title: "How do keyboard shortcuts work?"
category: "Using Atlassify"

---

Atlassify includes keyboard shortcuts for common actions, listed under **Settings → Keyboard Shortcuts**.

### General

- `h` — go home
- `n` — open My Notifications
- `u` — toggle unread only
- `p` — group by product
- `t` — group by title
- `f` — open Filters
- `r` — refresh notifications
- `s` — open Settings
- `a` — open Accounts (from Settings)
- `q` — quit the app

### Notifications list

- `↑` / `↓` — move between notifications
- `Shift` + `↑` — first notification
- `Shift` + `↓` — last notification
- `Enter` — expand notification
- `a` — change read state

You can also set a global shortcut to show or hide Atlassify from **Settings → System → Enable keyboard shortcut** (default `Cmd/Ctrl + Shift + G`).
