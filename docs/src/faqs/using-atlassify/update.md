---
title: "How do I update Atlassify?"
category: "Using Atlassify"
order: 2
---

Atlassify checks for updates automatically when the app launches and periodically after that.

When an update is available, it downloads in the background. Once downloaded, you'll be asked to **Restart** to apply it, or choose **Later** to apply it next time Atlassify restarts.

You can also check manually:

1. Right-click the tray icon
2. Select **Check for updates**

When a downloaded update is ready to install, right-click the tray icon and select **Restart to install update**.
