### Chrome Developer Tools

Use the built-in Chrome Developer Tools to inspect console logs, network requests, and more:

- **All platforms:** right-click the tray icon, then select **Developer → Toggle Developer Tools**
- **macOS:** `command + opt + i`
- **Windows / Linux:** `ctrl + shift + i`

### Application log files

Logs are written to a folder on your system:

- **All platforms:** right-click the tray icon, then select **Developer → View Application Logs**
- **macOS:** `~/Library/Logs/atlassify`
- **Windows:** `%USERPROFILE%\AppData\Roaming\atlassify\logs`
- **Linux:** `~/.config/atlassify/logs`
