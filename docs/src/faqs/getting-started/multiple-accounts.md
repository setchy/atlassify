---
title: "How do I add multiple accounts?"
category: "Getting Started"
order: 3
---

You can be signed in to multiple Atlassian accounts at the same time — for example, a work account and a personal account.

To add another account:

1. Open the **Accounts** screen from the Atlassify sidebar
2. Click **Add new account**
3. Sign in with the new account's username and API token

All signed-in accounts appear on the Accounts screen. You can refresh or sign out of each account individually.
