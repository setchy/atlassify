---
title: "Does Atlassify collect any data?"
category: "Getting Started"
order: 5
---

Atlassify includes **optional** anonymous usage analytics to help improve product quality and UX. This is off by default and can be toggled from **Settings → System → Share anonymous usage analytics**.

If enabled, Atlassify sends anonymous usage events (for example: screens visited and actions used). **Your Atlassian API tokens and notification content are never sent.**

See [PRIVACY.md](https://github.com/setchy/atlassify/blob/main/PRIVACY.md) for complete details.
