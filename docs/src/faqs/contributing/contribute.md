---
title: "How can I contribute to Atlassify?"
category: "Contributing"
order: 1
---

You can contribute to Atlassify by opening an issue or pull request on GitHub at [setchy/atlassify](https://github.com/setchy/atlassify).

Before contributing, please review our [CONTRIBUTING.md](https://github.com/setchy/atlassify/blob/main/CONTRIBUTING.md) guide for details on branch naming, the PR process, and code style.

Check out our [open issues](https://github.com/setchy/atlassify/issues) to see if there's an existing idea you'd like to work on.

Not a developer? You can still help by reporting bugs, improving documentation, or starring and sharing the project.
